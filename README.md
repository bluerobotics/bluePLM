# BluePLM releases

This repository holds the BluePLM desktop app's releases: the Windows and macOS installers and the files the app's
automatic updater reads. It contains no source code.

- Download the latest version: [Releases](https://github.com/bluerobotics/bluePLM/releases/latest)
- BluePLM on the web: [blueplm.io](https://blueplm.io)

Installed copies of BluePLM check this repository for updates by themselves and offer the new version when one is
published.
